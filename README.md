# Individu Slayer

A 2D top-down action game built with Godot 4. Fast combat, dashing, and rage mechanics inspired by Hyper Light Drifter.

## Story

You are a knight sworn to the Demon — a blade raised against heaven itself. The holy sentinels guard the path, but your mission is clear: hunt down and slay **Ramiel, the Right Eye of God**.

Fight through cursed lands, cut down the angelic guardians that stand in your way, and face Ramiel in a final showdown. Build your rage in combat to unleash devastating power — you'll need every edge you can get.

## Controls

| Action | Key |
|--------|-----|
| Move | WASD / Arrow Keys |
| Attack | Left Click |
| Dash | Shift |
| Fireball | Z (aim with mouse) |

## Gameplay Tips

- Landing hits builds **Rage**. At 80%, you enter Enraged mode — double damage, faster movement, and passive healing.
- Dashing and attacking cost **Stamina**. Manage it or you'll be caught vulnerable.
- The **Fireball** burns enemies, slowing them down. Save it for tough fights.
- Ramiel summons **spike storms** below half health. Keep moving.
